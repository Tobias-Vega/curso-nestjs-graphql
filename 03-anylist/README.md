# Dev

1. Clonar el proyecto
2. Copiar el archivo `.env.template` y renombrarlo a `.env`
3. Ejecutar
```
yarn install
```

4. Levantar la imagen (Docker Desktop)
```
docker compose up -d
```

5. Ejecutar el proyecto
```
yarn start:dev
```

6. Visitar `http://localhost:3000/graphql` para acceder a GraphQL Apollo Studio
